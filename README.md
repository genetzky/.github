# `.github`

This is the special `.github` repository for this GitHub organization. GitHub gives this repository organization-wide behavior in addition to treating it as a place for files:

- [`profile/README.md`](./profile/README.md) provides the introduction shown on the organization's GitHub profile.
- Eligible community health files placed here, such as `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, or issue and pull request templates, can serve as defaults for the organization's repositories when those repositories do not provide their own.

Use this repository for the organization profile and shared GitHub defaults, rather than for an individual software project.
